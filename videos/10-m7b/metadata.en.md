# Metadata · Module 7b (EN)

## Title
Test cycles, data and known issues: green with 8 bugs

## Description
My suite says 43 passed, and the same folder holds 8 confirmed defects. It's not a trick: they're marked as expected failures, and the day they get fixed, the test tells you. In this module you learn disciplined execution: the cycle protocol (retest what failed, run the full regression once at the close), documented datasets with caveats, @IGNORE with a ticket and an exit condition, and test.fail in Playwright. With restful-booker-quality-suite, war-paradigm and spendwise-qa-assessment.
