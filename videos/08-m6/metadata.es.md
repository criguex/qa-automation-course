# Metadata · Módulo 6 (ES)

## Título
API y contract testing: el contrato manda, no la respuesta

## Descripción
Una API de reservas recibe "depósito pagado: false" y guarda "true", con un 200 bien bonito. Si tu prueba solo mira el código de estado, ese bug pasa en verde. En este módulo validamos servicios contra su contrato con Zod, leemos errores de esquema campo por campo, probamos 401 vs 403, PUT vs PATCH y contratos de error, y dejamos la base limpia con finally aunque falle una aserción. Laboratorio con restful-booker-quality-suite, civica-playwright-challenge y karate-api-testing.
