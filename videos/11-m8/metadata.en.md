# Metadata · Module 8 (EN)

## Title
Test reporting and traceability: a counter isn't evidence

## Description
274 tests, 184 passed, 90 failed. If the report stops there, nobody can act on it. In this module you build reports with real evidence (steps, screenshots, video, traces, curl), classify every failure as product, test or environment, and trace requirement → test case → execution → evidence in both directions, whether your company uses Xray, TestRail or something else. With spendwise-qa-assessment, restful-booker-quality-suite, civica-playwright-challenge and war-paradigm.
