## Description

A test plan scores 76 against a gate of 70… and gets rejected. This module explains why: the oracle, the thing that decides whether a test passes. We split "does it run as specified?" from "is what it produced any good?", cover risk as probability times impact, the ISTQB principles that bite hardest day to day, and charter-based exploratory testing. Then we run experiment 01 from war-paradigm, where must criteria block and should criteria add points, and we break the oracle on purpose to see if it notices.

Module 01 of the free QA Automation course (level 1 · fundamentals).
