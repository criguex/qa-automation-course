## Description

Every happy-path test green… and an editor could make themself admin with a 200. A mutant found it. This module introduces WAR Paradigm, my way of testing the tester: generate the baseline, mutate one rule, audit with the guard, validate the verdict (PASS, KILLED or SURVIVED). We see it in four worlds: a broken law of physics (84 variants, 27 PASS, 54 KILLED, 3 SURVIVED), a step in a business flow (5 of 7 mutants caught and two real authorization bugs, one found while preparing this course), an AI answer (a 76 that still gets rejected), and a Claude Code hook that blocks pushes to main and, once attacked, turned out to have two real holes. We finish with this week's mutation: an editor approving with a 200 in the agent's test plan.
