## Description

I changed a title limit from 80 to 79 characters and the whole suite stayed green. This module covers the techniques that would have caught it: equivalence partitioning, boundary value analysis (the edge and both neighbors), decision tables, state transitions, pairwise and error guessing, plus how to write a proper test case and a bug report you can defend. We apply them to DocFlow, the app from war-paradigm's experiment 02, and turn up something no mutant was touching: a viewer who can create drafts. We finish with this week's WAR mutation: moving a boundary by one, in each direction.
