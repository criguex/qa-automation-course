## Title
AI-augmented QA: AI generates, you review every diff

## Description
Every happy-path test was green, and an editor could make themself an admin. When the code and its tests come from the same place, a green run proves less than it seems. In this module you put the whole method together: a director AI that plans, an IDE AI that executes, and you reviewing every diff; context before prompt, the five blocks of a good prompt, prompt packs with a checklist, hard rules in hooks, and mutants to find out whether generated tests have teeth. Built on the real war-paradigm experiments.
