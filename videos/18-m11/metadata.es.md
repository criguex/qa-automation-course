# Metadata ES · 18-m11

## Título
QA aumentado con IA: la IA genera, tú revisas cada diff

## Descripción
Todas las pruebas del camino feliz en verde, y un editor podía darse rol de admin. Cuando el código y sus pruebas salen del mismo lugar, un verde prueba menos de lo que parece. En este módulo armas el método completo: una IA directora que planea, una IA del IDE que ejecuta y tú revisando cada diff; contexto antes que prompt, los cinco bloques de un buen prompt, prompt packs con checklist, reglas duras en hooks y mutantes para saber si las pruebas generadas tienen dientes. Con los experimentos reales de war-paradigm.
