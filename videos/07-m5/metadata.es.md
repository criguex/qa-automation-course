# Metadata · Módulo 5 (ES)

## Título
Playwright + TypeScript: tu framework E2E desde cero

## Descripción
Mis pruebas de interfaz se pusieron en rojo sin que la app tuviera nada roto: la prueba esperaba un mensaje que sale una sola vez. En este módulo construimos un framework de Playwright + TypeScript que no cae en eso: locators semánticos, aserciones web-first, Page Objects inyectados con fixtures, login una vez con storageState, un flujo con dos roles y el trace viewer para diagnosticar sin sleeps. Todo con código real de mis repos públicos.
