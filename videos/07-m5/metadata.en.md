# Metadata · Module 5 (EN)

## Title
Playwright + TypeScript: an E2E framework from scratch

## Description
My UI tests went red while the app had nothing wrong with it: the test was waiting for a message that only shows up once. In this module we build a Playwright + TypeScript framework that avoids that trap: semantic locators, web-first assertions, Page Objects injected through fixtures, a single login reused with storageState, a two-role flow, and the trace viewer to debug without sleeps. All of it with real code from my public repos.
