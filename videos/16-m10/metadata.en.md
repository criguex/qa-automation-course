# Metadata EN · 16-m10

## Title
Performance and Cloud: percentiles, k6 and cold starts

## Description
A performance suite that always passes in CI… against a mock with no network. In this module you learn to measure performance for real: test types (load, stress, soak, spike), p95 and p99 instead of averages, SLIs and SLOs, k6 thresholds that turn the pipeline red on their own, serverless cold starts, and traces in CloudWatch. Built on real code from restful-booker-quality-suite and civica-playwright-challenge, plus the official k6 docs.
