# Metadata · Module 7 (EN)

## Title
BDD with Gherkin and Serenity: promises you can check

## Description
A feature file that reads perfectly and promises a success message, while its last two steps throw PendingException. In this module you learn BDD for real: the three amigos and concrete examples, declarative Gherkin with no clicks or selectors, reusable steps on top of Page Objects, Screenplay or an API client, Scenario Outline, Background and tags, and living documentation generated in the pipeline. Built on my repos selenium-cucumber-pom, serenity-screenplay-salesforce and karate-api-testing, flaws included.
