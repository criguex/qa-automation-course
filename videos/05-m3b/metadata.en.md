## Description

AI without context writes clean tests that test nothing. This module builds phase zero of my method: an Obsidian vault the assistant reads before every task, a CLAUDE.md with no secrets in it, and a hook that enforces what a prompt can't. We cover the three context layers (CLAUDE.md, memory and the vault), why you give enough context and not all of it, what MCP is, and we walk through the real vault from war-paradigm's experiment 03: READ FIRST, Golden rules, templates and the definition of done. We finish with this week's mutation: deleting a linked note and checking whether the link checker notices.

Module 05 of the free QA Automation course (level 1 · fundamentals).
