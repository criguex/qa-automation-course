## Descripción

Subí Playwright en el package.json, olvidé el lockfile y npm ci se negó a instalar. Ese error es lo que quieres desde el día cero. En este módulo dejamos listo el entorno: Node LTS (y por qué `brew install node` te da la Current), versiones fijadas y subidas a propósito, qué hace de verdad `npm ci`, por qué npx usa la versión del proyecto, el `.gitignore`, un README que sirve, conventional commits y el flujo rama → PR → review → merge. Usamos war-paradigm como repo de referencia y su CI como modelo. Cerramos rompiendo el entorno a propósito: sin lockfile, ¿lo nota el CI?

Módulo 04 del curso gratuito de QA Automation (nivel 1 · fundamentos).
