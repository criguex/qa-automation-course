## Description

I bumped Playwright in package.json, forgot the lockfile, and npm ci refused to install. That error is exactly what you want from day zero. This module gets your environment ready: Node LTS (and why `brew install node` hands you Current), pinning versions and upgrading on purpose, what `npm ci` really does, why npx uses the project's version, `.gitignore`, a README that actually helps, conventional commits, and the branch → PR → review → merge flow. We use war-paradigm as the reference repo and its CI as the model. Then we break the environment on purpose: no lockfile, does CI notice?

Module 04 of the free QA Automation course (level 1 · fundamentals).
